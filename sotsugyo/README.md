■ サービス概要
増え続ける「後で読む」技術記事を放置させず「何を学ぶか」の
目的意識を持って消化するための学習管理サービスです。単なるブックマークではなく、
読了予想時間の設定や、読後のアウトプット（メモ・実装完了）をセットで行うことで、
技術の定着を強力にサポートします。

■ 開発背景（このサービスへの思い）
プログラミング学習を開始して以来、Qiita、Zenn、公式ドキュメントなど、
毎日多くの有益な情報に触れるようになりました。
学びたい意欲から「とりあえずブックマーク」する習慣がつきましたが、気づけば「積読」は100件を超過。
**「どの記事が重要だったか忘れてしまう」「週末にまとめて読もうとして、
結局量に圧倒されて何もしない」**といった状況に陥りました。
また、苦労して読んだ記事も、一週間後には内容を忘れてしまい、
「読んだだけで満足していた自分」に強い課題感を持つようになりました。
この「情報の洪水に溺れる」状態を打破し、**「ただ読む」から「技術を習得する」
**ステップへ確実へと進める仕組みを作りたい。
自分と同じように情報の取捨選択や学習管理に悩む初学者の助けになりたいと考え、このサービスを企画しました。

■ ユーザー層について
メインユーザー： プログラミング初学者〜中級者理由：
覚えるべき技術が多岐にわたり、情報の取捨選択や学習管理に苦労している層が最も多いと考えたため。

■ サービスの差別化ポイント・既存ツールからの移行メリット
PocketやNotion、ブラウザのブックマーク機能などの既存ツールとの最大の違いは、「保存」ではなく「消化（定着）」に全エネルギーを注いでいる点です。

【比較表】
主な目的 ・既存ツール： 「忘れないように保存する」 ・本サービス： 「内容を理解し、習得する」
登録時のアクション ・既存ツール： URLを保存するだけ ・本サービス： 「何を知りたいか」を言語化して登録
読了後のアクション ・既存ツール： 記事を消す、またはアーカイブして終わり ・本サービス： 要約や実装コードを残し、成長を可視化
放置（積読）対策 ・既存ツール： 際限なく溜まり、埋もれがち ・本サービス： ダッシュボードでの強調表示やリマインド機能

■既存ツールから移行するメリット 
・迷わない 「今週読むべき記事」が強調されるため、ログインしてすぐに学習を開始できます。 
・忘れない アウトプット（3行要約等）が必須フローに含まれるため、記憶への定着率が格段に上がります。 
・自信がつく 消化した記事数や学習時間がグラフ化されるため、「これだけやった」という実感が得られます。

■ 機能候補
### MVPリリース時
ユーザー登録・ログイン機能
記事URL登録機能（OGP取得によるタイトル・画像自動表示）
「学びたいこと」メモ機能（登録時に目的を明確化）
学習ステータス管理（未読・読書中・完了）
ダッシュボード上でのリマインド機能（放置期間が長い記事の強調表示）
一覧表示・削除・検索機能

### 本リリース時
学習時間の可視化グラフ（Chart.jsなど）
優先度（高・中・低）による並び替え簡易的なリマインド通知機能（メールまたはプッシュ通知）
Chrome拡張機能（閲覧中のページを即座に登録）
SNSシェア機能（「今週は〇件の記事を消化しました！」）

■ 使用する技術スタック
フレームワーク: Ruby on Rails 7 (Ruby 3.2)
データベース: PostgreSQL
デプロイ先: Render または Railway

■ 使用予定のライブラリ
setomits/opengraph_parser: URLからOGP情報（タイトル、画像）を取得するために使用。
Chart.js: 学習データのグラフ化に使用。
Tailwind CSS: UIデザインを効率的に整えるために使用。
